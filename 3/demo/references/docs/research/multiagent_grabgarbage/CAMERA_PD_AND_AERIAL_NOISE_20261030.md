## 控制输入与特权边界

地面/腕相机的当前mask、RGB-D、标定及机器人自身位姿构成本地操作输入。相机坐标经外参和自身base pose转换，再由明确的工具/物体几何假设与IK生成关节目标，交给Kp/Kd位置跟踪；当前会话的 `task_implicit_gravity_bias` 是PD骨架加重力补偿，实际增益、desired target和补偿后的drive target分开记录。相机到PD桥仍需独立动作验收，不把几何候选直接称为已抓取。

无人机报告是粗候选，不作为机械臂最终定位。垃圾真实位姿、物理对象ID与接触见证只用于场景初始化和评估；不提供给感知/协同控制做隐藏定位。此前已知位姿检查仅作为保留的离线诊断，不是当前默认操作链。

原始真实图像和真实相机pose仍保留在评估记录中，以核查实际渲染/标定与误差注入；噪声不改写这些物理记录。这里是代码数据流边界，不是任意Python控制器的安全沙箱。当前首框、类别和初始跨相机对应仍有明确人工输入，必须继续标注受控基线，不能称自主发现或同物识别已完成。

## 真正注入的空中定位误差

[aerial_position_noise.py](../../../source/capabilitylab/capabilitylab/cooperative/aerial_position_noise.py) 默认三维位置误差RMS为0.10m：

```text
reported_xyz = rgbd_estimated_xyz + persistent_route_bias + per_exposure_jitter
RMS_3D(persistent_route_bias) = 0.08m
RMS_3D(per_exposure_jitter) = 0.06m
RMS_3D(total) = sqrt(0.08² + 0.06²) = 0.10m
```

两项为独立、各向同性、零均值高斯；固定项跨同一路由的曝光保持，因此反复平均不能把误差完全消掉。10cm是跨种子统计的三维RMS，不是每轴标准差或每次误差的硬上限。独立seed默认20261030，同一干净曝光输入确定重放，不消费NN/运控随机数。

注入位置位于实际 `localize_mask` 之后、共享记忆和 `accept_aerial_proposal` 之前。空中表面中心、点云及AABB同步平移，避免旁路保留未加噪精确坐标；协方差每轴增加0.1²/3，原不确定半径再加约95%高斯径向报告半径0.1617m。原有RGB-D误差仍存在，10cm是额外报告误差模型，不代表真实无人机精度已标定。

地面/腕部定位与native sink不加这项空中报告误差。公开定位行只保存带噪值与模型尺度，不提供无噪坐标、误差实现值或seed；实验合同保存seed供复现。当前front/tail两个实际入口默认启用，旧调用者显式保留的 `None` 只用于历史无注入基线，冻结运行不追改。
