Nerfies: Deformable Neural Radiance Fields

Keunhong Park, Utkarsh Sinha, Jonathan T. Barron, Sofien Bouaziz, Dan B Goldman, Steven M. Seitz, Ricardo Martin-Brualla

This is a Capability-Aware website demonstration using an existing paper. For the original research, visit Nerfies's official website.

Overview

Turning casually captured videos into portraits that can be viewed from new angles. Nerfies models a moving subject using a deformation field and a neural radiance field.
